# 食材めやす 公開サポート文書

プライバシーポリシー、利用上の注意・免責事項、お問い合わせ窓口をGitHub Pagesで公開する専用リポジトリです。

公開URL: https://nkusumot.github.io/shokuzai-meyasu-support/

`main` のルートをGitHub Pagesの公開元としています。HTMLとCSSのみで、アクセス解析や広告スクリプトは使用しません。文書を変更するときは本文と最終更新日を更新してください。

公開文書本文の正本はこのリポジトリです。アプリ本体には本文を複製せず、上記URLの各ページをアプリ内で表示します。運営：Naoki Kusumot。お問い合わせ：nkusumot.apps@gmail.com。
